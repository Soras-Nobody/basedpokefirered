# Pokémon Based FireRed and LeafGreen

This is the source code of English Pokémon Based FireRed and LeafGreen.

It builds the following ROM images:

* **basedpokefirered.gba**
* **basedpokeleafgreen.gba**
* **basedpokefirered_rev1.gba**
* **basedpokeleafgreen_rev1.gba**
* **basedpokefirered_switch.gba**
* **basedpokeleafgreen_switch.gba**
* **basedpokefirered_classic.gba**
* **basedpokeleafgreen_classic.gba**
* **basedpokefirered_rev1_classic.gba**
* **basedpokeleafgreen_rev1_classic.gba**
* **basedpokefirered_switch_classic.gba**
* **basedpokeleafgreen_switch_classic.gba**
